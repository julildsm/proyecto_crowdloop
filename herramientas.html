Herramientas de calidad

Las herramientas ayudan a probar, revisar y automatizar. Filtra por categoría o busca por nombre para encontrar la que necesitas.

14 herramientas

  • Gestión de pruebas

    Jira

    Seguimiento de incidencias y tableros ágiles para gestionar defectos y tareas.

  • Gestión de pruebas

    TestLink

    Gestión de casos de prueba, planes y resultados de ejecución (código abierto).

  • Automatización

    Selenium

    Automatiza navegadores para ejecutar pruebas funcionales de aplicaciones web.

  • Automatización

    Cypress

    Pruebas de extremo a extremo que se ejecutan dentro del navegador.

  • Automatización

    JUnit

    Framework de pruebas unitarias para Java.

  • Automatización

    Postman

    Diseña, ejecuta y automatiza pruebas de APIs.

  • Análisis estático

    SonarQube

    Detecta errores, vulnerabilidades y deuda técnica en el código.

  • Análisis estático

    ESLint

    Analiza JavaScript para encontrar errores y hacer cumplir un estilo común.

  • Control de versiones

    Git

    Sistema de control de versiones distribuido para registrar y comparar cambios.

  • Control de versiones

    GitHub

    Aloja repositorios y facilita la revisión de código con Pull Requests.

  • Integración continua

    Jenkins

    Servidor de automatización para compilar, probar y desplegar.

  • Integración continua

    GitHub Actions

    Flujos automáticos que se ejecutan desde el repositorio ante cada cambio.

  • Rendimiento y seguridad

    Apache JMeter

    Pruebas de carga y de rendimiento sobre aplicaciones y servicios.

  • Rendimiento y seguridad

    OWASP ZAP

    Escáner de seguridad para encontrar vulnerabilidades en aplicaciones web.
